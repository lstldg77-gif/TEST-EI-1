# 한국사 퀴즈 게임

## 프로젝트 개요

Python으로 만든 **콘솔 기반 4지선다 퀴즈 게임**입니다.
메뉴에서 번호를 선택해 퀴즈를 풀고, 새 퀴즈를 등록하고, 목록과 최고 점수를 확인할 수 있습니다.
추가한 퀴즈와 최고 점수는 `state.json` 파일에 저장되어 프로그램을 다시 실행해도 유지됩니다.

- 언어: Python 3 (표준 라이브러리만 사용, 별도 설치 불필요)
- 주요 학습 내용: 클래스/객체, 입력 검증과 예외 처리, JSON 파일 입출력, Git 브랜치 작업

## 퀴즈 주제와 선정 이유

**주제: 한국사**

- 고조선부터 근현대까지 시대별로 대표적인 사건과 인물을 골고루 다룰 수 있어 문제를 만들기 좋습니다.
- 한국사능력검정시험 등 실제로 공부할 일이 많은 분야라, 게임으로 반복해서 풀며 복습하는 데 도움이 됩니다.
- 정답이 명확한 사실(인물, 연도, 장소) 위주라 4지선다 형식과 잘 맞습니다.

## 실행 방법

```bash
# 1. 저장소 복제
git clone https://github.com/lstldg77-gif/TEST-EI-1.git
cd TEST-EI-1

# 2. 실행 (Python 3.8 이상)
python main.py
```

실행하면 다음 메뉴가 나타나며, 번호를 입력해 기능을 선택합니다.

```
========================================
          한국사 퀴즈 게임
========================================
  1. 퀴즈 풀기
  2. 퀴즈 추가
  3. 퀴즈 목록
  4. 점수 확인
  5. 종료
========================================
메뉴를 선택하세요 (1-5):
```

## 기능 목록

| 번호 | 기능 | 설명 |
|---|---|---|
| 1 | 퀴즈 풀기 | 저장된 퀴즈를 차례로 출제하고 정답/오답을 바로 알려줍니다. 모든 문제를 풀면 정답 수와 점수(100점 만점)를 보여주고, 최고 점수보다 높으면 갱신해 저장합니다. 퀴즈가 없으면 안내 메시지를 출력합니다. |
| 2 | 퀴즈 추가 | 문제, 선택지 4개, 정답 번호(1~4)를 입력받아 새 퀴즈를 등록하고 즉시 파일에 저장합니다. |
| 3 | 퀴즈 목록 | 등록된 모든 퀴즈의 문제와 선택지를 보여줍니다. (정답은 공개하지 않음) 퀴즈가 없으면 안내 메시지를 출력합니다. |
| 4 | 점수 확인 | 최고 점수를 보여줍니다. 아직 퀴즈를 풀지 않았다면 안내 메시지를 출력합니다. |
| 5 | 종료 | 데이터를 저장하고 프로그램을 종료합니다. |

### 입력 및 예외 처리

- 입력값의 앞뒤 공백을 제거한 뒤 처리합니다. (예: ` 1 ` → `1`)
- 빈 입력, 숫자가 아닌 입력(예: `abc`), 허용 범위 밖 숫자(예: 메뉴 `9`, 정답 `0`)는 안내 메시지 후 다시 입력받습니다.
- `Ctrl+C`(KeyboardInterrupt) 또는 입력 종료(EOFError)가 발생하면 안내 메시지를 출력하고, 데이터를 저장한 뒤 안전하게 종료합니다.
- `state.json`이 없으면 기본 퀴즈로 시작하고, 손상된 경우 안내 메시지를 출력한 뒤 기본 데이터로 복구합니다.

## 파일 구조

```
TEST-EI-1/
├── main.py              # 프로그램 진입점 (QuizGame 생성 후 실행)
├── quiz_game.py         # QuizGame 클래스: 메뉴, 입력 처리, 게임 진행, 파일 저장/불러오기
├── quiz.py              # Quiz 클래스: 문제 1개(문제/선택지/정답), 출력, 정답 확인, dict 변환
├── default_quizzes.py   # 기본 한국사 퀴즈 7개 (Quiz 인스턴스 목록)
├── state.json           # 실행 데이터 (프로그램이 자동 생성, Git에는 올리지 않음)
├── .gitignore
└── README.md
```

### 클래스 구조

- **`Quiz`** — 속성: `question`(str), `choices`(list, 4개), `answer`(int, 1~4)
  메서드: `display()`, `is_correct()`, `correct_choice()`, `to_dict()`, `from_dict()`
- **`QuizGame`** — 속성: `quizzes`(list[Quiz]), `best_score`(int 또는 None), `state_file`
  메서드: `run()`, `show_menu()`, `read_number()`, `read_text()`, `play()`, `add_quiz()`, `list_quizzes()`, `show_score()`, `load()`, `save()`

## 데이터 파일 설명 (state.json)

- **경로**: 프로젝트 루트의 `state.json` (`main.py`와 같은 폴더)
- **역할**: 퀴즈 목록(기본 + 사용자가 추가한 퀴즈)과 최고 점수를 저장해 다음 실행 때 그대로 불러옵니다.
- **인코딩**: UTF-8 (한글이 그대로 보이도록 `ensure_ascii=False`로 저장)
- **저장 시점**: 퀴즈 추가 직후, 퀴즈 풀기 완료 후, 프로그램 종료 시(Ctrl+C/EOF 포함)
- **Git 관리**: 사용자마다 달라지는 실행 데이터이므로 `.gitignore`에 등록되어 있습니다. 파일이 없으면 첫 실행 시 기본 퀴즈로 시작하고 종료할 때 생성됩니다.

### 스키마

| 키 | 타입 | 설명 |
|---|---|---|
| `quizzes` | list | 퀴즈 목록 |
| `quizzes[].question` | str | 문제 |
| `quizzes[].choices` | list[str] | 선택지 4개 |
| `quizzes[].answer` | int | 정답 번호 (1~4) |
| `best_score` | int 또는 null | 최고 점수 (0~100점), 아직 풀지 않았으면 `null` |

### 예시

```json
{
  "quizzes": [
    {
      "question": "훈민정음을 창제한 조선의 왕은?",
      "choices": ["태조", "태종", "세종", "정조"],
      "answer": 3
    }
  ],
  "best_score": 86
}
```
